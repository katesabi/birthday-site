# happy birthday, bestie!

this project is a personalized birthday landing page for my online friend. the goal is to create a warm, heartfelt experience with a playful memphis-style touch, making the page feel like a digital hug.

## original concept
🎨 custom design built by myself.

## key features
- ✅ responsive layout — works nicely on mobile, tablet, and desktop.  
- ✅ memphis-inspired design — bold vibes with a cozy, personal feel.  
- ✅ modular structure — html, css, and javascript separated for easy tweaks.  
- ✅ interactive element — a button that smoothly scrolls to the “reasons” section.  

## what this project practices
- building a single-page, emotion-focused layout.  
- styling with a distinct visual tone (memphis influence).  
- adding simple javascript to power smooth scrolling.  
- organizing content into clear sections: hero, reasons, gallery, and personal message.  

## how to run
1. make sure the `images` folder with all photos is in the same directory as `index.html`.  
2. open `index.html` in a browser.  
3. styles are in `style.css`; scripts are in `script.js`.
