birthday tribute site for my online bestie  

this repo contains a simple birthday tribute site built with html, css, and vanilla js. the site celebrates a long‑distance friendship with a memphis‑style design, animated cards, a photo gallery, and heartfelt messages.  

what’s included  
hero section  
a bold memphis‑styled headline and a “launch the celebration” button that triggers smooth scrolling.  

8 reasons you’re amazing section  
tilted, hoverable cards with colorful styling—each card shares a short reason why the friend is special.  

good times gallery  
a 3‑column grid of photo cards with bold drop‑shadows and a slight tilt; each card rotates slightly on hover.  

message section  
a warm, centered message block with a soft pink background and a personal note.  

rainbow footer  
a cheerful footer with colored dots and a small love note.  

test cases (manual checks)  
check that the hero section fills the full viewport height on different screen sizes.  
verify that clicking the button scrolls smoothly to the reasons section.  
confirm that card hover effects (rotation, scale, shadow) work as expected.  
ensure the gallery grid adapts to mobile (1 column) and tablet (2 columns) breakpoints.  
make sure all images display correctly and the mask effect is visible in supported browsers.  
check that the footer appears at the bottom and the colored dots are aligned.  

how to run the site  
create a folder for the project and add index.html, style.css, and script.js.  
add an images folder inside the project directory and place 6 photos named photo‑1.jpg through photo‑6.jpg.  
open index.html in a browser.  

notes  
the design uses a playful memphis aesthetic with bold colors, tilted elements, and subtle animations.  
no external libraries are required—only plain html, css, and js.  
the site is responsive and works on mobile, tablet, and desktop screens.  
you can easily customize the text, colors, and images to match your friend’s personality.
